# Founder portraits

Portraits are stored locally when a public profile image could be matched confidently to the founder. The image source is also linked from that founder's profile in `js/founders-data.js`.

- `manan-issar.jpg` — public LinkedIn profile image: https://in.linkedin.com/in/issarmanan
- `ankit-dhir.jpg` — public profile image, also shown on HabileLabs' official biography: https://www.habilelabs.io/company/about
- Twenty `.webp` portraits in this folder come from exact-name public eChai founder profiles. Their source profile links are listed in the corresponding founder records.

Profiles without a confidently matched portrait display a designed initials treatment. The older named `.svg` initials images remain in the folder for reference but are no longer used by the site.
